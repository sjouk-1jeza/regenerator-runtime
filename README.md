# chip.tsx

[![Build Status](https://travis-ci.com/user/chip.tsx.svg?branch=master)](https://travis-ci.com/user/chip.tsx)

Este repositório contém o código-fonte do livro "chip.tsx".

This repository contains the source code of the "chip.tsx" book.

## Requisitos / Requirements

Building requires [tasks]:

```bash
$ cargo install tasks --vers 0.4.0
```

## Construindo / Building

Para construir o livro / To build the book:

```bash
$ tasks build
```

O resultado estará na subpasta `book`. 
The output will be in the `book` subdirectory.

Para rodar os testes / To run tests:

```bash
$ tasks test
```
